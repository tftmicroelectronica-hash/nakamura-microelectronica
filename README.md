### Publicación en GitHub Pages

1. Ingresar al repositorio de GitHub.
2. Abrir Settings.
3. Seleccionar Pages.
4. En Source elegir Deploy from a branch.
5. Seleccionar la rama main.
6. Seleccionar la carpeta /root.
7. Presionar Save.
